## 🎮 The game

Kids spin around a high bar, and **every spin is +1 SPEED**. Let go at the right moment and you launch down a road that runs through world after world. The farther you fly, the more **WINS** you earn. WINS buy shoes that make you faster, and rebirths unlock stronger bars. It's a simple loop a six-year-old gets in five seconds, polished so it still feels good on the hundredth flight.

```mermaid
flowchart LR
    A["🤸 SPIN<br/>+1 SPEED per spin"] --> B["🚀 LET GO<br/>launch + flips"]
    B --> C["🌍 FLY<br/>steer through worlds"]
    C --> D["🏆 LAND<br/>WINS by distance"]
    D --> E["👟 SHOES<br/>more speed"]
    E --> A
    D --> F["🔄 REBIRTH<br/>new bars, x2 x3 x4"]
    F --> A
    D --> G["🥚 EGGS<br/>flying sidekicks"]
    G --> A
```

## 🎨 Art: every model made in code

Every creature, shoe, bar, prop and sky in the game is generated by **Python scripts in Blender** (29 of them), one style guide for the whole cast. A pipeline then uploads each model to Roblox and drops it into Studio with no hand-exporting. Every part is checked alone against Roblox's moderation rules before upload.

## 🤖 How it's built: one developer and an AI team

I'm the game designer and producer. The building is done by **Claude Code** set up as a small studio. Each role is a separate agent with its own instructions, tools and limits, running on the cheapest model that can do that job well.

```mermaid
flowchart TB
    IDO(["🧑 Ido: designer, producer, final say on every publish"])
    CAP["🧭 Captain<br/>plans the day, writes briefs,<br/>drives Roblox Studio, merges"]
    IDO <--> CAP
    CAP --> W["🔧 Builder<br/>one scoped change<br/>in its own git worktree"]
    CAP --> BS["🎨 Blender artist<br/>models + renders + uploads"]
    CAP --> GH["📈 Sim tuner<br/>every economy number<br/>through the simulator first"]
    CAP --> SC["🔎 Researcher<br/>other games, Roblox rules"]
    W --> HK["🦅 Reviewer<br/>red-teams every build<br/>against what's live"]
    W --> TP["🕹️ Play tester<br/>plays the real flows in Studio"]
    RD["📊 Stats analyst<br/>fresh analytics every morning"] --> CAP
    SG["🧠 Advisor<br/>second opinion<br/>on the hardest calls"] -.-> CAP
```

**The day loop:** 07:15 stats report → one quick fix → the day's build → review and play test → I publish in the evening.

**Nothing ships on "looks good".** Every build has to pass, in this order:

1. **The in-game test harness.** About **26,000 assertions** run inside a live Studio session.
2. **A hash check** that every script in Studio matches the source.
3. **A clean console**, then screenshots of the real flows on phone-sized screens.
4. **A code review** against the live version, plus a play-tester pass.
5. **Fresh analytics** after release, compared with the same hours before.

Hard-to-undo things stay with me: publishing, saved-data migrations, Robux prices and deleting anything.

## 📊 Run like a live game

- **36 updates in the first 11 days** after launch, each logged with what changed and why.
- Every economy number goes through a **Python pacing simulator** first (12 versions so far), with targets for how long each step should take.
- **Funnels on every first-time step** (spawn → train → first flight → shoes → rebirth → hatch), read every morning straight from Roblox's analytics API.
- In the first two weeks the **average session grew from ~7.3 to ~9 minutes**, and **1 in 7 sessions passes 20 minutes**. **over 90% of kids on phones** used the new steering on its first day.
